# 我蛇了 / I SNAKED

一条穿越到像素 RPG 世界的贪吃蛇——它不能停下，吃了会变长。身长即血条、弹药与牢笼：吐豆攻击会把自己打短，用身体把敌人围成"窒息监狱"，断尾保命，放置环形节点封口成环。

当前为**玩法原型阶段**（纯浏览器单文件，零依赖）。

## 运行

直接双击打开 `prototype/index.html` 即可，无需安装任何东西。

## 操作

| 按键 | 功能 |
|---|---|
| WASD / 方向键 | 移动（8 方向即时转向 · 点按转向 · 长按 2 倍速冲刺 · 不能停） |
| 长按 J / 空格 | 站桩火力姿态（定身连射，每蠕动射出一颗豆子，身长即弹匣） |
| K / Shift | 断尾（切掉第 2 节之后的身体化作豆子弹开，回收一半） |
| F | 在蛇头处放置环形节点（固定地面，蛇身完全通过后自动回收充能） |
| P / R | 暂停 / 重开 |

开始界面可选择**教学关卡**（8 步引导全部核心能力）或**沙盒模式**。
